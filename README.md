# Photography Journal Website

A visually driven web application designed to showcase photographic work and journaling. This project focuses on clean UI/UX design and responsive layouts to provide a seamless viewing experience across different devices.

**Live Demo:** [photography-journal-website.vercel.app](https://photography-journal-website.vercel.app)[cite: 1]

---

## 📌 Project Overview

This project was developed as part of my **1st Semester University curriculum**.[cite: 1] It served as a foundational exploration into front-end web development, focusing on structured HTML architecture, advanced CSS styling, and basic interactive elements using JavaScript.

---

## 🚀 Features

*   **Multi-page Navigation**: Includes dedicated pages for a blog, gallery, login, and user registration.
*   **Dynamic Gallery**: A clean layout to showcase high-resolution photography.
*   **Responsive Design**: Optimized for various screen sizes using CSS media queries.
*   **User Authentication UI**: Includes a front-end interface for login and signup processes.
*   **Submission Portal**: A dedicated "Submit" page for adding new content.

## ⚙️ How to Run Locally

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/AashirGilani/Photography-Journal-Website.git](https://github.com/AashirGilani/Photography-Journal-Website.git)
    ```
2.  **Navigate to the folder:**
    ```bash
    cd Photography-Journal-Website
    ```
3.  **Open the project:**
    Simply open `homepage.html` in your preferred web browser.
